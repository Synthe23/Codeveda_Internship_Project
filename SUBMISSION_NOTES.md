# Codveda Submission Notes

The project implements the Codveda brief as a single coherent application.

Recommended demo order:
1. Register/login to show JWT authentication.
2. Create, update, filter and delete tasks.
3. Open the app in a second browser tab and demonstrate Socket.io updates.
4. Explain MongoDB/Mongoose schema and indexes.
5. Show `/graphql` and run a task query/mutation.
6. Explain the ES Module backend (`"type": "module"` and `import`/`export`).
7. Record a short walkthrough video and attach the GitHub repository when submitting.
